# Папа любит мясо — стартовая версия игры

## Как запустить
1. Открой папку проекта.
2. Дважды кликни по `index.html`.
3. Игра откроется в браузере.

## Как открыть в Codex
Открой всю папку `papa-meat-game` как проект / workspace.

## Что уже работает
- Главное меню.
- Карьерная лестница.
- Игровая смена для всех должностей.
- Опыт и повышение должности.
- Сохранение прогресса в браузере.
- Сброс прогресса.

## Структура
- `index.html` — интерфейс.
- `styles.css` — оформление.
- `app.js` — игровая логика.
- `assets/` — сюда можно положить логотип и изображения.
